AIDE


Par défaut, lorsque vous tapez une expression à rechercher, par exemple Windows 2000, le moteur recherchera les deux mots dans le forum. Par exemple dans ce cas il retournera tous les messages qui contiennent Windows et 2000. et tous les messages qui contiennent 2000.

Dans le cas d'une recherche avancée, si vous souhaitez faire une recherche plus précise, il faut inclure + devant les mots. Ainsi dans notre exemple, en tapant +Windows +2000, le moteur retournera tous les messages contenant Windows et 2000. Il pourra ainsi retourner des titres comme "Windows 2000 se vend à merveille" et "Windows 98 a battu tous les records en l'an 2000" mais plus "Windows est le concurent de Linux". Si vous tapez 2000 +Windows +98, le moteur retournera les messages contenant 2000 ou Windows et 98.

Vous pouvez également lancer une recherche sur une partie d'expression en utilisant le caractère *. Si vous tapez par exemple for* le forum retournera les messages contenant l'expression 'for' avec n'importe quoi derrière (fort, forum, etc).
Attention, vous ne pouvez utiliser les * qu'en fin d'expression. Vous pouvez les combiner avec la fonction +, en entrant par exemple +Win* +20*.
