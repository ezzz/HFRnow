Au final je crée un topic sur les beta tests, ça sera plus simple à gérer que par MP
 
Si vous êtes intéressé par la beta de HFR+, voici le lien pour l'invit pour la beta : https://testflight.apple.com/join/48GS63Ze
 
Il faut installer l'appli de test TestFlight et ensuite l'invitation vous permet d'installer la version beta
A savoir que ça remplace la version officielle de l'AppStore mais qu'il est possible de faire retour arrière en réinstallant l'appli depuis l'AppStore
 
Tout type de retour est le bienvenu: bugs, regressions, évolutions, améliorations, une idée géniale... tant que c'est dans la bonne humeur
 
Merci d'utiliser ce topic pour remonter les bugs de la version beta. On garde le topic habituel pour les releases officielles
 
Bon tests
