# UX decisions pending (H.3)

**Role of this file:** the decisions the operator and the contributors (ezzz, Bybifok) must make before M1–M4 can be called a port of the legacy app. Directive H.3 of [#368](https://github.com/ezzz/HFRnow/issues/368), `cloud/ui-convergence`. **Delete this file** once every row is decided and recorded in its spec, its issue and [#379](https://github.com/ezzz/HFRnow/issues/379) (AGENTS.md, one file, one role).

How to read it:
- **Option A** is the legacy behaviour at `2440d79`. **Option B** is the change that the specs propose or the app code already ships.
- **GAP** ids point to [GAP-LEGACY-VS-SWIFT.md](GAP-LEGACY-VS-SWIFT.md). Its `H.1` column says whether each row is a port (a) or an evolution (b).
- The recommendation follows the operator's principles in [FEATURES.md](../FEATURES.md#ux-principles-operator): "Preserve what works", and "Defaults keep the legacy UX; changes are opt-in settings".
- **Shipped** means the merged code already behaves as option B, so picking A needs a small (a) follow-up lot.
- To decide, comment `UXD-NN: A` or `UXD-NN: B` (with any nuance) on [#379](https://github.com/ezzz/HFRnow/issues/379).
