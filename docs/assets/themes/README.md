# Theme and icon reference visuals

Validated by the operator as the latest version (2026-11-10), made on 2026-10-28 from his requests ([THEMES.md](../../THEMES.md), [ICONS.md](../../ICONS.md)). Original work for SwiftHFR: the drawings are rendered by the Blender scripts in [`tooling/illustrations/`](../../../tooling/illustrations/README.md), no downloaded mesh, texture or image.

| Folder | Content |
|---|---|
| `boards/` | mock-up boards (JPEG): `theme-noel`, `theme-samain`, `events` (arrivals, popups, packing, 14 July), `theme-legacy`, `theme-swift`, `theme-retro`, `selectors` (Réglages › Thème, Réglages › Icône de l'app), `style-charter`, `da-styles` and `da-closeup` (art-direction candidates; style 1 chosen), `blender-closeup` (Marianne, the realism reference), `icons-legacy`, `icons-beta`, `icons-xface`, `icons-season` |
| `icons/` | each new icon at 1024 px: JPEG render and SVG master (`noel-redface.svg` is left out: over the repository's 2 MB file limit; regenerate it with `tooling/illustrations/icons.py`) |
| `renders/` | the Blender renders of every subject (transparent PNG), as placed on the boards |
| `tokens/themes.json` | the token draft of the themes on the boards (colours per variant, accent presets, families and windows, events); LOT-188 turns it into the engine's format |

Not here: the « OG clair / OG gris » board (it showed real member names and a real topic title; the OG themes wait for the stylesheet capture #728), the board HTML sources (generated by `tooling/illustrations/build.py`).

Phone mock-ups use anonymized category names and topic titles. Mock-ups show intent, not pixel-exact layouts: the app follows the lot specs.
