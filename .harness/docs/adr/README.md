# Décisions d'architecture (ADR)

Un fichier par décision : `NNNN-titre-court.md`, gabarit [TEMPLATE.md](TEMPLATE.md). Statut : Proposé · Accepté ·
Remplacé par NNNN. Format : Contexte → Options → Décision → Conséquences. Une décision qui n'est pas dans un ADR n'est
pas une décision. Un ADR accepté ne se réécrit jamais : on le remplace.

Ce dossier contient les ADR **du cadre**. Chaque projet tient les siens dans son propre `docs/adr/`.
