# Démarrer un lot

Issues visées : $ARGUMENTS

Règles de référence : `.harness/docs/METHODOLOGY.md` §2 (sinon `${CLAUDE_PLUGIN_ROOT}/docs/METHODOLOGY.md`) et le
`CLAUDE.md` du projet, qui l'emporte.

1. **État réel d'abord** : `git fetch origin`, lire la branche d'intégration (`.harness/config.json` →
   `integration_branch`, sinon `CLAUDE.md`). Lire chaque issue **et tous ses commentaires** (outil GitHub).
2. **Prête ?** Pour chaque issue, s'arrêter et le dire si :
   - elle est déjà prise en charge par une autre session (commentaire « Pris en charge », label `pris en charge`) ;
   - elle porte `à clarifier` ou `bloqué`, ou une dépendance (`Dépend de`, plan des lots) n'est pas fermée ;
   - elle porte `hôte: mac` et la session tourne en cloud (`CLAUDE_CODE_REMOTE=true`) ;
   - il manque un label d'axe (type, priorité, modèle, taille) : le proposer plutôt que deviner ;
   - ses entrées n'existent pas (données, captures, sources réglementaires, accès).
   Comparer le label `modèle:` au modèle de la session : plus exigeant → le signaler à l'opérateur avant de commencer.
3. **Doublons et chevauchements** : chercher les issues et PR (ouvertes et fermées) sur le même sujet, et les PR
   ouvertes qui touchent les mêmes fichiers.
4. **Prise en charge** : sur chaque issue, un commentaire :
   ```
   Pris en charge — branche `claude/<lot>`
   - <plan en 3 à 5 puces : quoi, où, comment c'est testé>

   ---
   _Generated by [Claude Code](https://claude.ai/code)_
   ```
   (et le label `pris en charge` si le projet l'utilise).
5. **Branche** : `git switch -c claude/<lot> origin/<intégration>` (ou un worktree si d'autres lots tournent en
   parallèle : `git worktree add ../<projet>-<lot> -b claude/<lot> origin/<intégration>`).
6. **Spec** : un lot a sa spec `docs/lots/LOT-XXX-*.md` (gabarit `docs/lots/TEMPLATE.md`) ; un bug ou une tâche
   s'appuie sur l'issue. Relever les leçons de `LESSONS.md` qui s'appliquent (portée du projet) et les garder en tête.
7. Rendre compte en 5 lignes : issues prises, branche, plan, risques, ce qui sera à valider sur Mac.
